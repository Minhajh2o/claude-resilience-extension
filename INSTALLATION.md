# Installation & Configuration Guide

Follow these steps to set up the Claude Resilience Extension on Chrome or Brave.

## Prerequisites
- Google Chrome or Chromium-based browser (Brave, Edge).
- A free account on [Resend](https://resend.com) (free tier includes 3,000 emails/month; no credit card required).
- A free account on [Claude.ai](https://claude.ai).

## Step 1: Get Your Free Email API Key
1. Sign up at [resend.com](https://resend.com).
2. Navigate to **API Keys** in the dashboard.
3. Click **Create API Key**, name it `claude-resilience`, and copy the token (`re_...`).
